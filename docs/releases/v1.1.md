# AUTO-Superset v1.1 — Superset 1.28 native recovery

Runtime: **9.9.5-public.1** · Superset desktop/host/CLI: **1.28.0+** · Platform: **macOS**

## What's new

- Prefer Superset's native OpenCode root session identity and automatic same-session resurrection.
- Adopt replacement terminals only after verifying persisted successor lineage, the same session/host/workspace/agent, and exclusive writer ownership.
- Keep the workspace supervisor and protected `NATIVE_RESUMING` state.
- Retain one quota-gated explicit `--resume-session` fallback after native grace. Retire the already-exited source through Superset before launching to prevent a later duplicate resurrection.
- Separate available PTY failure details from daemon timeouts, attach cancellation and uncertain control-channel outcomes.
- Update the README, workflow, installer/doctor migration checks and upstream change inventory.

The **v9.9.4.1 Free→Go exact-session verifier is unchanged**. Durable handoffs, quota supervision, AUTO_PROJECT inheritance, Clean Coordinator Chat and recovery ownership checks remain active.

## Upgrade

1. Stop active AUTO work. Upgrade Superset to 1.28.0, reopen it to finish host migrations, and launch OpenCode once to regenerate its native integration. Then quit Superset and stop AUTO supervisors.
2. Download and extract `AUTO-Superset-v1.1.zip`, or update your existing Git checkout from `main`.
3. Run `bash install.sh --dry-run`, then `bash install.sh`. If you previously selected providers explicitly, use that same `--providers` selection for both commands.
4. Reopen Superset and run `python3 scripts/setup.py doctor`.

The default provider selection is OpenCode + Codex. Installation preserves unrelated settings and prints a restore point.
